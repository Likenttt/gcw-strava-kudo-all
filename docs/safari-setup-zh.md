# 三步开始使用 Kudo All

[English](https://kudoall.li2niu.com/help/safari/) · [功能介绍](https://kudoall.li2niu.com/safari/zh/)

**Mac Safari · macOS 12+ · 一次性购买，无订阅**。价格以所在商店为准。

## 1. 下载并打开

[从 Mac App Store 下载](https://apps.apple.com/app/apple-store/id6458730808?pt=125713495&ct=kudo_safari_readme&mt=8)，然后从“应用程序”打开 **Garmin Connect Web Kudo All** 一次。

## 2. 启用并授权

进入 **Safari → 设置 → 扩展**（旧版为“偏好设置”），勾选 **Kudo All**。打开使用的网站，点击扩展图标，按提示选择 **Always Allow on This Website（始终允许当前网站）**，无需授权全部网站。

## 3. 登录、刷新、点赞

**在 Safari 中**登录 [Strava](https://www.strava.com/dashboard) 或 [Garmin Connect](https://connect.garmin.com/app/newsfeed)，按 **⌘R 刷新**，点击右上角 **Kudo All**。Garmin 入口是上传按钮旁的心形图标，也可从 Safari 工具栏面板点击 **点赞当前动态**。

仅处理已加载、尚未点赞的活动；滚动加载更多后可再次点击。不会自动滚动或在后台自动点赞。

<details>
  <summary>按钮没出现，或者未连接？</summary>
  <p>确认已启用扩展、允许当前网站、登录账号并刷新。工具栏面板中点 <strong>重新连接（Reconnect）</strong>，再检查<strong>已连接（Connected）</strong>和<strong>可点赞动态（Available kudos）</strong>；重新连接不会直接点赞。数量为零可能表示已加载的活动都已点赞。图标隐藏时，可通过<strong>显示 → 自定工具栏</strong>添加。</p>
  <p>使用 Safari 用户场景时，为当前用户场景启用扩展。无痕浏览权限为可选项。</p>
</details>

<details>
  <summary>中国区动态与结果说明</summary>
  <p>Garmin 中国区：<a href="https://connect.garmin.cn/app/newsfeed">connect.garmin.cn</a> 或 <a href="https://connectus.garmin.cn/app/newsfeed">connectus.garmin.cn</a>。兼容旧版 <code>/modern/newsfeed</code>；个人主页和单条活动页不适用。本版本仅用于 Mac，不支持 iPhone/iPad。</p>
  <p><strong>页面已确认</strong>只代表页面显示的点赞状态，不是独立服务端回执。出现未确认结果时会停止执行；先检查页面，再决定是否重试。执行时保持动态页打开。</p>
</details>

<details>
  <summary>关闭或卸载</summary>
  <p>进入<strong>Safari → 设置（或偏好设置）→ 扩展</strong>，取消勾选即可停用；点<strong>卸载</strong>并按提示移除 Mac 应用即可删除。刷新已打开的动态页。<a href="https://support.apple.com/zh-cn/102343">Apple 操作说明</a>。</p>
</details>
